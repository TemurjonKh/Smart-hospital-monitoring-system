
# Smart Hospital Patient Monitoring System

## Project Overview

This project presents a MATLAB-based Smart Hospital Monitoring System designed using signal processing concepts from Signals and Systems.

The system simulates biomedical and environmental sensors, processes signals using LTI systems, applies Fourier analysis, performs filtering and feature extraction, and visualizes patient status through MATLAB App Designer.

The project demonstrates practical applications of:
- Time-domain LTI systems
- Fourier Transform
- Signal filtering
- Frequency-domain analysis
- Smart alert systems
- Biomedical signal monitoring
- Laplace/stability concepts

---

# Features

## ECG Monitoring
- ECG signal generation
- LTI filtering using convolution
- Signal shifting and scaling
- FFT spectrum analysis

## Smart Alerts
- Abnormal ECG detection
- Automated warning system
- Patient status monitoring

## Respiration Monitoring
- Respiration signal simulation
- Air quality (CO₂) monitoring

## HRV Analysis
- RR interval extraction
- Tachogram visualization
- HRV frequency spectrum

## SpO₂ & Blood Pressure
- PPG waveform simulation
- Oxygen saturation estimation
- Blood pressure trend visualization

## MATLAB App Designer Dashboard
- Multi-tab monitoring interface
- Interactive graphs
- Gauges and status lamps
- Smart hospital dashboard
